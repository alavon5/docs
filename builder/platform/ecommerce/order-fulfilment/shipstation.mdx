### ShipStation fulfilment 

Ship faster with less effort. The ShipStation integration automatically sends your orders to ShipStation, so you can create labels, manage carriers, and fulfill orders all in one place.

No manual exports. No copy-paste. Just a smooth handoff from checkout to delivery.

Open your ShipStation dashboard and select > **Account** > **API Settings**

![](/images/builder/8b01968d1a377163.png)

Next you'll need to create a new API Key that will connect your store to ShipStation.

Within the **API Settings** page select > **Generate API KEY**

![](/images/builder/146694181f78cd5c.png)

Next select the API expiration length and click the generate button.

![](/images/builder/2e7d29e91d357051.png)

You'll now see your new API Key credentials.

![](/images/builder/8be80819b6a066b2.png)

Now head back to your builder dashboard and select the Ecommerce tab in the navigation bar at the top, then click settings. From here you will now see the **Add Integration** button.

![](/images/builder/f8e41ce2844f586b.png)

Once selected, select the ShipStation integration as shown.

![](/images/builder/3585123f54ad3799.png)

Now paste your ShipStation API KEY and Secret Key in the pop out shown below.

![](/images/builder/b9a15b76b810ed33.png)

Once you have inserted your API Key and Secret Key - Shipstation is now connected to your ecommerce store.

Below is an example checkout that automatically displays your preferred ShipStation Carriers. You'll also see in the checkout summary that the shipping costs are automatically calculated for you.

![](/images/builder/383ae9ea4b6aba3a.png)

Once an order has been processed you will now see the order within your ShipStation orders dashboard:

![](/images/builder/d66196f1d1bb7b48.png)

And your customer will also be sent your system email.

![](/images/builder/ae0491ac2f6ffc0e.png)
