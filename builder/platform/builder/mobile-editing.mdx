When editing your website in mobile view, everything you have created on the desktop view will be displayed as normal. 

The mobile editor enables you to edit how your mobile view is displayed if you want to make some changes here and there. Upon **opening the mobile editor** you will see some buttons to the right side of the editing panel. 

![](/images/builder/04eed4c1fa966971.png)

### **Existing Design**

The displayed view in the mobile editor will be the exact same content as the desktop design you have created. Below we'll show you how to edit the existing content.

![](/images/builder/dd7c0ef73e949272.png)

When hovering over a portion of the design 'container' you will see the settings display to the left side. Here you can: 

* **Edit the container**
* **Hide/display the container in desktop/mobile**
* **Stretched - Stretches the content width**
* **Reverse Column order - Move anything at the top, to the bottom.** 

<Note>
**Note:** If any changes are made in the settings 'Cog icon' those changes will be made on the desktop view also.
</Note>

***

### **Adding Additional Content**

You can add additional content just to the mobile view if required, that will not been seen on the desktop view. To do so, simply open the widget panel to the left and drop any widget in place. You will see a little mobile icon displayed to the widget. This denotes that it's just mobile content.

### **Mobile Header Layout**

To the right side of the mobile editing display, click the Mobile Header Layout button - Once selected a new panel will display. Here you can: 

#### **Configure the menu display styling:**

* Basic
* Mirrored
* Circles Dock

![](/images/builder/c13434b4e95c08a1.png)

***

### **Menu Style**

Here you can select the type of menu style to display when a visitor click the menu button:

* **Side navigation 'Default'**
* **Overlay menu 'like dock'**

#### **Side navigation**

When a visitor click your menu the contents of the menu will display in a slide out panel. 

![](/images/builder/82321e6f4bf0d046.png)

#### **Overlay Like Dock**

Overlay displays in the full window when a visitor clicks the menu. 

![](/images/builder/de49922998e7c0db.png)

### **Adding widgets to your overlay menu** 

When selecting the overlay like dock menu style you can additionally add more content. Ie you can add any widget element to your menu. 

![](/images/builder/fd7c2a0c1597c47e.png)

<Note>
**Note:** This can only be used when the overlay menu (like doc) is selected. 
</Note>

Once selected you will see a new button display to the top right of the mobile editing window, called Overlay menu area.

![](/images/builder/22584723d982dc27.png)

Click the overlay menu area button to start adding menu content. First you will see a blank container, that you can start editing just how you would edit any page/column you have already created. 

![](/images/builder/36a5069a27675c39.png)

Once you have added your own design to the overlay menu area, go ahead and save. When a visitor clicks on your mobile menu, they will now see your new layout designed menu area. 

![](/images/builder/40d1548ff93c74d7.png)

***

### **Circles Dock**

The circles dock menu display is like a web application display, for example, instead of having the generic top of mobile menu, the circles dock will display at the bottom of the mobile view, and have buttons, instead of menu text. 

Select the circles dock menu display option in the top right side: 

![](/images/builder/9af4ca2584256042.png)

You will now see - Left actions and Right actions displayed. 

#### **Adding an action**

To add an action select which side you want to use first, ie left or right. Once selected you can add an icon, optional text and a link to the button. 

![](/images/builder/2e88d3c9f7068444.png)
