Like any other email template, you can fine-tune this **double opt-in confirmation email** using the **drag-and-drop email editor** for full personalization.

**What’s Pre-Configured in the Template:**

* **System Fields Included** – Website name, essential allocated fields.
* **Default Content** – Confirmation message designed for seamless user onboarding.

**How to Customize:**

* **Edit or Delete Fields** – Modify the preset system details as needed.
* **Use the Drag-and-Drop Editor** – Adjust layout and branding effortlessly.
* **Refine Messaging** – Make it more engaging and suited to your audience.

A **straightforward way** to enhance **user experience and brand consistency!**

![](/images/builder/336603c5c7deeb18.png)

To add any further fields to the system email template you can do so by selecting the text editor when typing and click the **Tag** icon. The tag icon will then display the specific fields you can add to the system template as shown below.

![](/images/builder/1f113bd557cebcba.png)

Here you will see all the specific fields allocated to the double opt-in confirmation system email.

Also all CRM [properties](/builder/platform/crm/properties) that can be added to the email too. Note if you have any custom properties you have created they will be listed here too.
