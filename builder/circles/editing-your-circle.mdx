**Welcome to the main editing canvas for your Circle.** In this section, we’ll cover all the editing elements and features within this canvas, helping you get familiar with the layout and easily locate the tools you need. Below you'll see the main Circle editing Canvas.

![](/images/builder/dfa327c0d6c61f0e.png)<p>Circle Canvas</p>

Let's start with the basic elements located to the left side of the screen. 

<Tip>
**Note:** The basic elements on the left side are page-level editing and setting tools. These controls apply to whichever page you are currently viewing or editing, allowing you to make necessary adjustments directly from this panel. To make any edits to the main Circle, use the top bar. 
</Tip>

### Page Level Settings

Page level settings enable you to quickly edit things like, access levels, Content availability and more. To access the page level settings, simply select the gear icon to the left: 

![](/images/builder/17b7c034884d9dc0.png)

From here you'll be able to:

* **Page Name**: A title added to the specific page tab.
* **Page URL**: A dedicated URL for a specific page.
* **Show Page Description**: Small text below the Page Name
* **Hidden Page**: This will make your page invisible from your circle members 'Often used when editing or updating page content'
* **Access Level**: Each page can have its own access level - [click here to read more](/builder/access-levels)
* **Content Availability**: Have full control when content is viewable to members - Read more
* **Track Content Completion**: Enables the member to edit and view the status of the page content.
* **Layout in the Navigation Bar**: Change the prefix of the page name with a icon, image, text etc.
* **Adding a Badge**: Add a badge next to the page/group name. Example: If you have some new content, you can add a colour branded badge next to the title.
