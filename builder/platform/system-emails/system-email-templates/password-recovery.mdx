Just like any other email template, you can tailor the **password recovery email** using the **drag-and-drop editor** for seamless personalization.

**What’s Pre-Configured in the Template:**

* **System Fields Included** – Website name and allocated recovery details.
* **Default Content** – Pre-set instructions for users to reset their passwords.

**How to Customize:**

* **Modify or Remove Fields** – Adjust system placeholders to fit your needs.
* **Use the Drag-and-Drop Editor** – Personalize layout, colors, and branding effortlessly.
* **Enhance Messaging** – Ensure clarity and user-friendliness for smooth password recovery.

A **simple yet essential way** to provide **a secure and branded password reset experience!**

![](/images/builder/47095d15d25c99fa.png)

To add any further fields to the system email template you can do so by selecting the text editor when typing and click the **Tag** icon. The tag icon will then display the specific fields you can add to the system template as shown below.

![](/images/builder/1f113bd557cebcba.png)

Here you will see all the specific fields allocated to the password recovery system email.

Also all CRM [properties](/builder/platform/crm/properties) that can be added to the email too. Note if you have any custom properties you have created they will be listed here too.
