This is the core text element for adding headings to your pages, supporting H1–H6 tags for proper structure and SEO, along with a full inline formatting toolbar and a set of eye-catching Text Effects for making key words stand out

![](/images/builder/7d1c300759d13340.png)

#### **Why use it:**

* **Proper heading structure matters**, using true H1–H6 tags (not just large text) helps both SEO and accessibility, ensuring search engines and screen readers understand your page's content hierarchy.
* **Quick, familiar text formatting**, bold, underline, alignment, color, and sizing are all available inline, so you can style text without leaving the editor.
* **Text Effects add personality**, dynamic effects turn a static heading into something more engaging, useful for hero sections or anywhere you want a word or phrase to pop.

![](/images/builder/8537afba6fff24b1.png)

Upon double clicking the text, the **text editor panel** will display above it. Here you can select:

* Font size 'hierarchy' from H1-H6 
* Bold
* Underline, italic, sub-script, super-script and strike-through
* Font family / Font size in PX
* Line height, increase/decrease the height between the text height spacing
* Text color
* Background text color
* Alignment
* Add a link
* Effects
* Remove formatting
* **Ask AI** generate or rewrite headline copy

### **Text effects:** 

(applied to specific words/phrases)

**Highlight**: draws attention to a word or phrase with a colored highlight. Choose the **Color**, **Highlight Style** (e.g., Underline), and **Placement** (e.g., under text).

![](/images/builder/2076bf3fff35abb3.png)

**Rotate Text**: cycles through multiple phrases in place (e.g., swapping "Headline" for other words). Add rotating phrases (one per line), set **Color**, choose an **Animation** style (e.g., Slide Up), and control **Speed** and **Animation Speed**.

![](/images/builder/ecd60e0ce53c4e30.png)
