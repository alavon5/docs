**Within your Circle, you can create additional pages as well as groups.** Groups consist of multiple pages organized within a dedicated section, allowing for better content management and accessibility.

To create a new page or group, simply click the Add button: 

![](/images/builder/3802e79cc3cfc07e.png)

**To create a new page, click on the Page tab.** Once selected, you’ll be prompted to enter a page name—this will also serve as the title displayed in the tab. From there, you can add content and adjust your page-level settings. [Learn more about page-level settings here](/builder/circles/editing-your-circle).

### Create a new Page Group

**A page group is a collection of pages consolidated into a single, easy-to-navigate tab.** Within a page group, you can create various types of content, including landing pages, video collections, courses, community posts, and more. Let’s dive into the group settings below.

From here you'll be able to:

* **Group Name**: A title added to the specific page tab.
* **Group URL**: A dedicated URL for the group.
* **Show Group Description**: Small text below the Page Name
* **Hidden Group**: This will make your group invisible from your circle members 'Often used when editing or updating page content'
* **Access Level**: Each page can have its own access level - [click here to read more](/builder/access-levels)
* **Content Availability**: Have full control when content is viewable to members - Read more
* **Track Content Completion**: Enables the member to edit and view the status of the page content.
* **Layout in the Navigation Bar**: Change the prefix of the page name with a icon, image, text etc.
* **Adding a Badge**: Add a badge next to the page/group name. Example: If you have some new content, you can add a colour branded badge next to the title.
* **Enrolment Required**: The visitor will be asked to click a button to view content and enrol to view it.

### Adding Content to a Group

With your Page Group now created, you can go ahead and start adding content to that group. To start adding content, click the page group as shown below: 

<Tip>
A page group is identified by an arrow as shown below, this can be edited later on if required. Read more here
</Tip>

![](/images/builder/e0e343db384634bb.png)

**After clicking on the group, you can add a new page.** The image below illustrates the interface displayed when adding a new page to the group.

![](/images/builder/1bded60fcc41c70d.png)

For this example, we're going to create 2 pages within this group. Both pages will lead to a course video. 

If you are not sure how to add or even set up a new page, go to this link below.

[Editing Your Circle](/builder/circles/editing-your-circle)

![](/images/builder/e9b817cd1cba5296.png)

**In the image above, we’ve added two new pages, using the page image as a video thumbnail for display purposes.** When a member clicks on either Video 1 or Video 2, they will gain access to the dedicated page created for each course video.

Beyond simple video pages, you can utilize various builder widgets, just as you would when creating any page or funnel to enhance interactivity and customization.
