---
title: "How to use AiDen"
description: "Ask better questions, share helpful context, and use AiDen for navigation, page planning, troubleshooting, orders, and creative work."
---

AiDen works best when you describe the result you want. You do not need to learn special commands or use technical language.

## Open AiDen

Open the AiDen help panel from the lower-right corner of a supported Bosscart dashboard page. Enter your request in the message field, select the microphone to speak, or attach a screenshot when you want AiDen to review something visible on screen.

## Find your way around

Ask AiDen where to find a feature or how to reach a specific part of Bosscart.

Try requests such as:

- "Take me to my email subscribers."
- "Where do I manage bookings?"
- "Show me where to edit my community settings."
- "How do I get back to the website builder?"

AiDen uses verified Bosscart destinations and the page you are currently viewing to provide relevant guidance.

## Plan pages and troubleshoot

AiDen can recommend native Bosscart widgets, outline page sections, explain builder controls, and help diagnose layout or configuration problems.

For a stronger answer, include:

- The type of page or funnel you are building
- The audience and action you want visitors to take
- What you have already tried
- Whether the issue affects desktop, tablet, mobile, or every view
- A screenshot of the current page or problem

Example requests:

- "Plan a lead-generation landing page for my coaching business."
- "Walk me through the builder screen."
- "Which widgets should I use for a product comparison section?"
- "This spacing looks wrong on mobile. Can you review the screenshot?"

<Note>
  AiDen provides plans and instructions that you apply in the visual builder. It does not edit Bosscart source code or claim that a suggested design has already been built or deployed.
</Note>

## Work with orders

When order access is connected for your workspace, AiDen can look up orders, check their current status, and help prepare supported updates.

Try requests such as:

- "Find order 1042 and tell me its status."
- "Check whether this customer's order has shipped."
- "Prepare an update for this order."

AiDen asks for confirmation before applying an order change. If order access is not configured, it will explain what connection is needed.

## Create content and visuals

AiDen can help draft page copy, produce structured build plans, and create reusable CSS or JavaScript guidance when native builder controls are not enough. It can also assist with generating or editing images and other supported creative work.

Try requests such as:

- "Write hero copy for a bookkeeping service."
- "Create an image for this blog post."
- "Remove the background from this product photo."
- "Give me a reusable build plan for this landing page."
- "Help me add a mobile-only layout adjustment."

When code is needed, AiDen should tell you which element to identify, where to place the code, and how the result should behave across device sizes.

## Get better results

- **Lead with the goal.** Explain the outcome you want before listing details.
- **Be specific.** Include the page, product, audience, or customer involved.
- **Share what you can see.** A screenshot gives AiDen direct visual context for layout and troubleshooting questions.
- **Ask for a format.** Request a checklist, step-by-step walkthrough, build plan, copy draft, or code snippet when that would be useful.
- **Review business changes.** Confirm order or customer-impacting actions only after checking the proposed update.

## Current limits

- AiDen guides work inside the Bosscart platform; it does not access or change application source code.
- Page and funnel recommendations are implementation plans, not automatically published designs.
- Exact access to orders, customer data, creative tools, and other actions depends on the connections enabled for your workspace.
- AiDen does not assume how hidden controls behave. A screenshot can help when the visible interface differs from the documentation.
